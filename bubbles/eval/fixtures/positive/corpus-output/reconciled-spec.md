# Spec — Record submission limits

## Requirements

- A submission accepts a maximum of 250 items per request.

## Reconciliation note

This spec previously documented a maximum of 100 items. The implementation was
raised to 250 without the spec being updated, so the two had drifted. The spec
is reconciled to the implemented value here, and the previously documented
figure is recorded rather than silently overwritten -- the drift itself is the
finding worth keeping.
