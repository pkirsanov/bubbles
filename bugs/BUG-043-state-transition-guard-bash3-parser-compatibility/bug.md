The parser failure prevents the guard from reaching any transition check.

## Expected Behavior

The source guard must pass syntax parsing under both named interpreters. The
fix must preserve transition behavior under the supported Bash runtime.

Parser compatibility does not declare full Bash 3 runtime support. Existing
runtime version policy remains outside this defect.

## Actual Behavior

The operator reported interpreter-dependent parse results on identical source
bytes. Bash 3 exits before the guard can evaluate repository state.

## Root-Cause Status

The precise parser origin is unconfirmed. Line 4016 contains a long-standing
quoted `echo` statement, so the reported line may be a parser recovery point.

Current source inspection found grouped regular expressions in
`dod_item_claims_execution()` and an associative-array declaration later in the
same evidence section. The design requires controlled reduction before choosing
either construct as the cause.

## Impact

- The source guard cannot be syntax-checked with macOS system Bash.
- An installed downstream copy can fail before emitting a structured verdict.
- The failure blocks certification rather than weakening a transition rule.
- Direct downstream patching would create install drift.
