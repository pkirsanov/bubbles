# User Validation - BUG-035 Validation Control-Plane Churn And Scope Overreach

## Automation Readiness

- [ ] Persistent pre-fix fixtures reproduce every defect.
- [ ] Scenario-specific fixes pass focused tests.
- [ ] Adversarial controls preserve high-risk validation floors.
- [ ] Full framework validation and release readiness pass.

Automation readiness does not grant human acceptance.

## Checklist

- [ ] A bounded session resumes without repeated `continue` prompts.
- [ ] Accepted proof is reused across compatible validation consumers.
- [ ] Certification no longer requires manual reconciliation of duplicate facts.
- [ ] An unrelated finding routes without taking over the parent task.
- [ ] Validation depth follows the resolved risk of the change.
- [ ] An unchanged assurance closure prevents equivalent replay.
- [ ] Source bug files use a packet form declared by the registry.
- [ ] Payload closure returns a stable verdict on unchanged bytes.
- [ ] Changed-only validation works from detached source revisions.
- [ ] Large-output assertions return stable results.
- [ ] One contaminated performance sample retries before release failure.
- [ ] Core-tier lint returns one verdict on unchanged validator bytes.
