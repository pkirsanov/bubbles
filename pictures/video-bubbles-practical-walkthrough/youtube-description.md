## Title
Bubbles Practical Setup Walkthrough: From Install To Proven Result

## Description
This walkthrough shows a synthetic, end-to-end example of how a developer would use Bubbles from setup to an actual result.

The example is intentionally fictional, so it does not expose any real project internals. It shows the practical shape: install Bubbles, run a simple specialist agent, use coordinator workflows, create artifacts, inspect example specs/scopes/reports/state, and understand what a validated result looks like.

Use this video after the overview videos when someone asks, “Okay, but what do I type and what does it produce?”
