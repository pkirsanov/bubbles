# YouTube Description

## Title
Bubbles Validation Playbook: Gates, Reviews, Hardening, And Proof

## Description
This is the deeper technical guide to how Bubbles keeps AI coding work honest.

Bubbles does not just ask an agent to write code and hope for the best. It routes work through structured artifacts, specialist agents, workflow phases, review passes, regression checks, hardening, gap analysis, security review, simplification, docs alignment, raw execution evidence, and certification gates.

This video covers the quality system: why gates exist, what evidence means, how review agents help, how chaos/simplify/harden/gaps/security agents fit in, and why Bubbles treats “done” as a claim that must be proven.
